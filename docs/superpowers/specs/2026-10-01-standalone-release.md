# Standalone Steps 1 and 2

Track3DGS must contain the continuous-route reconstruction, regional training,
cleanup, ownership, QC, export and Unity review work developed since handover.
Users must be able to run it without QuestSBTC. Preserve the existing trained
masters and the older section pipeline. Do not include capture footage, model
datasets, virtual environments, Unity caches or QuestSBTC gameplay assets.

Promote the latest sky-volume experiments into configurable commands. Preserve
the centre/ellipse tests and iterative visible-alpha method, distinct-position
consensus, separate edit/validation frames, full SH attributes and source-row
provenance. Cleanup remains experimental and produces a separate review result.
Include the synthetic lateral seam diagnostic as a reusable command.

Ship a minimal Unity 6000.3.19f1 / URP 17.3.0 viewer with the redistributable
pinned Gsplat 1.4.0 renderer and the recorded local fixes. Include its license,
notices and patch history. Route markers and two-slot raw/clean/core/sky review
must work on generated data from any route; no QuestSBTC dependency. Preserve
the two-visible-model limit, translation-only caches, one RUB conversion,
camera-pose-preserving before/after changes and GPU resource release.

Document utility/GPU setup, portable paths, inputs, commands, outputs, quality
limits and the downstream VR3DGS/application boundary. Verify CPU tests, a real
GPU cleanup reproduction, and the independent Unity viewer. Commit and push
the verified changes and previously unpublished Step 2 commits to origin.
